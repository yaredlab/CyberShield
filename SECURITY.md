| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |

## Reporting a Vulnerability

The CyberShield project takes security and responsible disclosure seriously.

If you believe you have discovered a security vulnerability, flaw, or data handling issue within this project, please notify us directly via email:

📧 **Contact**: [schemchy27@gmail.com](mailto:schemchy27@gmail.com)

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Details of your testing environment

We will acknowledge receipt within 48 hours and work with you to remediate any legitimate vulnerabilities promptly.
